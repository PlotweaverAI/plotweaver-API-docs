Speech to text runs on **STORM ASR 2.0**, one model for Yoruba, Hausa, Igbo, Nigerian Pidgin, Nigerian English and speech that mixes them, such as Yoruba and English in the same sentence.

- **No language needed.** The model recognises what is being spoken.
- **Written properly.** Capitals, punctuation and full Yoruba tone marks; numbers come back as words.
- **Any length.** Long recordings are split at natural pauses, so they come back complete.
- **Fast.** A typical clip comes back in well under a second.

## Transcribe a file

`POST /v1/transcriptions` with `multipart/form-data`:

<CodeGroup>

```bash curl
curl -X POST https://api.plotweaver.app/v1/transcriptions \
  -H "X-API-Key: $PLOTWEAVER_API_KEY" \
  -F file=@voice-note.m4a
```

```python Python
import os
import requests

with open("voice-note.m4a", "rb") as f:
    r = requests.post(
        "https://api.plotweaver.app/v1/transcriptions",
        headers={"X-API-Key": os.environ["PLOTWEAVER_API_KEY"]},
        files={"file": f},
        timeout=300,
    )
r.raise_for_status()
print(r.json()["text"])
```

```javascript Node.js
import { readFile } from "node:fs/promises";

const form = new FormData();
form.append("file", new Blob([await readFile("voice-note.m4a")]), "voice-note.m4a");

const res = await fetch("https://api.plotweaver.app/v1/transcriptions", {
  method: "POST",
  headers: { "X-API-Key": process.env.PLOTWEAVER_API_KEY },
  body: form,
});
console.log((await res.json()).text);
```

<ParamField body="file" type="file" required>
  Audio or video: wav, mp3, m4a, ogg, flac, mp4, mov, webm and more. Up to 25 MB.
</ParamField>

<ParamField body="language" type="string">
  `yo`, `ha`, `ig`, `pcm` or `en`. Optional: it is recorded with the request, and the model does not need it.
</ParamField>

<ParamField body="timestamps" type="string">
  `segment` for timed pieces. See below.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  `json`, `srt` or `vtt`.
</ParamField>

## Timestamps

Add `timestamps=segment` and the transcript comes back in timed pieces. The audio is split at pauses with voice activity detection, and each piece runs up to 15 seconds: the right size for subtitles, and for cutting silence in an edit.

```bash
curl -X POST https://api.plotweaver.app/v1/transcriptions \
  -H "X-API-Key: $PLOTWEAVER_API_KEY" \
  -F file=@interview.mp4 -F timestamps=segment
```

```json
{
  "request_id": "b0c7...",
  "language": null,
  "text": "Ẹ kú àárọ̀. Ẹ káàbọ̀ sí ètò wa.",
  "audio_duration_s": 9.4,
  "model": "storm-asr-2.0",
  "segments": [
    { "start": 0.0, "end": 1.9, "text": "Ẹ kú àárọ̀." },
    { "start": 3.1, "end": 9.4, "text": "Ẹ káàbọ̀ sí ètò wa." }
  ]
}
```

## Subtitles

For a ready subtitle file instead of JSON, send `response_format=srt` or `response_format=vtt`:

```bash
curl -X POST https://api.plotweaver.app/v1/transcriptions \
  -H "X-API-Key: $PLOTWEAVER_API_KEY" \
  -F file=@episode-3.mp4 -F response_format=srt \
  -o episode-3.srt
```

Timed transcripts take up to 2 hours of audio, and the price is the same as plain text. [Subtitle a video](/build/video-subtitles) adds translation for subtitles in another language.

<Tip>
For long videos, send only the sound track. It uploads much faster and stays well under 25 MB:

```bash
ffmpeg -i episode-3.mp4 -vn -ac 1 -ar 16000 -c:a libopus -b:a 32k episode-3.ogg
```
</Tip>
