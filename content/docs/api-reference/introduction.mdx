| | |
|---|---|
| **Base URL** | `https://api.plotweaver.app` |
| **Authentication** | `X-API-Key: pw_prod_...` on every request except `GET /v1/languages` |
| **Request bodies** | JSON, or `multipart/form-data` for file uploads |
| **Responses** | JSON, `audio/wav` for speech, raw PCM for streaming speech |
| **OpenAPI** | [`openapi.json`](https://docs.plotweaver.app/openapi.json) |

Pick an endpoint from the menu to see its parameters and responses, and try it live with your key in the playground.

## Endpoints

| Area | Endpoints |
|---|---|
| Languages | `GET /v1/languages`, `GET /v1/languages/{code}` |
| Voices | `GET /v1/voices`, `POST /v1/voices`, `GET /v1/voices/consent`, `GET`, `PATCH`, `DELETE /v1/voices/{voice_id}`, `GET /v1/voices/{voice_id}/audio` |
| Text to speech | `POST /v1/speech`, `POST /v1/speech/stream`, `POST /v1/speech/clone` |
| Speech to text | `POST /v1/transcriptions`, [`WSS /v1/transcriptions/stream`](/api-reference/realtime-transcription) |
| Translation | `POST /v1/translations` |
| Documents | `POST /v1/documents/text` |
| Usage | `GET /v1/usage/summary` |
