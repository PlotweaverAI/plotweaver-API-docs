`POST /v1/translations` translates text between any two of `en`, `yo`, `ha`, `ig` and `pcm`. STORM MT is built for Nigerian names, places and phrasing.


```bash tab="curl"
curl -X POST https://api.plotweaver.app/v1/translations \
  -H "X-API-Key: $PLOTWEAVER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "How are you doing today?", "source_language": "en", "target_language": "ha"}'
```

```python tab="Python"
import os
import requests

r = requests.post(
    "https://api.plotweaver.app/v1/translations",
    headers={"X-API-Key": os.environ["PLOTWEAVER_API_KEY"]},
    json={
        "text": "How are you doing today?",
        "source_language": "en",
        "target_language": "ha",
    },
    timeout=60,
)
print(r.json()["translated_text"])
```


```json
{
  "request_id": "4e7d...",
  "source_language": "en",
  "target_language": "ha",
  "translated_text": "Yaya kake yau?",
  "pivoted": false,
  "pivot_intermediate_text": null,
  "model": "storm-mt"
}
```

| Field | Notes |
|---|---|
| `text` | Up to 2,000 characters per request. Split longer text at sentence or paragraph ends |
| `source_language` | `en`, `yo`, `ha`, `ig` or `pcm` |
| `target_language` | `en`, `yo`, `ha`, `ig` or `pcm` |

## Pairs without English

A pair that does not include English, such as `yo` to `ig`, is translated through English. The response then has `"pivoted": true` and the English in between as `pivot_intermediate_text`, so you can see exactly how the meaning travelled. Spot-check pivoted pairs before production use.

## Translate, then speak

Translation pairs naturally with text to speech: translate a message, then voice the result in the same language.

```python
text = translate("We are open on Saturday from nine.", "en", "yo")
audio = speak(text, "yo", voice_id="aderonke")
```
