---
title: "Voiceover from a document"
description: "Turn an article, PDF or report into one narrated audio file."
---

Narrate a news story, a policy document or a book chapter in a few lines of code. The [documents](/documents) endpoint is free; you pay only for the speech.

```python
import os
import re
import subprocess
import requests

API = "https://api.plotweaver.app/v1"
HEADERS = {"X-API-Key": os.environ["PLOTWEAVER_API_KEY"]}

# 1. Get the readable text (a link here; send files={"file": ...} for a PDF or .docx)
doc = requests.post(
    f"{API}/documents/text",
    headers=HEADERS,
    data={"url": "https://example.com/news/story"},
    timeout=120,
).json()
print(doc["title"], doc["characters"], "characters")


# 2. Split into parts of up to 5,000 characters, at paragraph ends
def parts(text: str, limit: int = 4800):
    chunk = ""
    for para in re.split(r"\n\s*\n", text):
        if chunk and len(chunk) + len(para) + 2 > limit:
            yield chunk
            chunk = ""
        chunk = f"{chunk}\n\n{para}" if chunk else para
    if chunk:
        yield chunk


# 3. Voice each part in order
files = []
for i, part in enumerate(parts(doc["text"])):
    r = requests.post(
        f"{API}/speech",
        headers=HEADERS,
        json={"text": part, "language": "en", "voice_id": "tola"},
        timeout=300,
    )
    r.raise_for_status()
    name = f"part-{i:03}.wav"
    open(name, "wb").write(r.content)
    files.append(name)

# 4. Join the parts into one file
with open("parts.txt", "w") as f:
    f.writelines(f"file '{name}'\n" for name in files)
subprocess.run(["ffmpeg", "-y", "-f", "concat", "-safe", "0", "-i", "parts.txt", "-c", "copy", "story.wav"], check=True)
```

<Note>
A single paragraph longer than 5,000 characters is rare, but if your documents have them, split those paragraphs at sentence ends too.
</Note>

## Narrate in another language

Translate each part first (up to 2,000 characters per translation request), then voice it in the target language. See [Translation](/translation).

## Know the cost first

`characters` in the documents response tells you how much text there is before you spend anything. See [Billing](/billing) for how speech is counted.
