PlotWeaver speaks **86 languages**. The five Nigerian languages have every service. The others have text to speech, and most of them voice cloning too.

| Service | Languages |
|---|---|
| Text to speech | 86 |
| Voice cloning | 70 |
| Speech to text | 5: `yo`, `ha`, `ig`, `pcm`, `en` |
| Translation | Any pair of `yo`, `ha`, `ig`, `pcm`, `en` |
| Streaming speech and real-time transcription | 5: `yo`, `ha`, `ig`, `pcm`, `en` |

Languages are addressed by code (`yo`) or by name (`Yoruba`), in any letter case.

## The live list

`GET /v1/languages` needs no key and is always current. Filter it with `?service=tts`, `tts_clone`, `asr` or `translation`.

```bash
curl "https://api.plotweaver.app/v1/languages?service=asr"
```

```json
[
  {
    "code": "yo",
    "name": "Yoruba",
    "services": ["tts", "tts_clone", "asr", "translation"],
    "tts_models": ["storm-v1", "storm-gust", "storm-v3"],
    "default_tts_model": "storm-v1",
    "default_voice_id": "aderonke"
  }
]
```

## How a request finds its model

You normally never choose a model. The API picks one from the language and the voice, and the `X-Model` response header tells you which engine answered. Pin one with `"model"` when you need to.

| Model | Used for | Chosen when |
|---|---|---|
| `storm-v1` | STORM v1.5, the built-in Nigerian voices. Highest quality, streams. | The language is `yo`, `ha`, `ig`, `pcm` or `en` and no cloned voice is given |
| `storm-gust` | STORM Gust 1.0: voice cloning in the Nigerian languages, and the fastest streaming | You use a voice cloned in a Nigerian language, or ask for `"mode": "speed"` |
| `storm-ensemble` | STORM Ensemble 3.0: built-in voices for 57 African languages outside Nigeria. Whole files only. | The language has Ensemble voices |
| `storm-v3` | STORM v3: 70 African languages, with a preset voice or cloning. Also available for the Nigerian languages if you prefer its sound. | Any other language, and cloning outside Nigeria |

## Nigerian languages

| Language | Code | Speech | Cloning | Transcription | Translation | Default voice |
|---|---|---|---|---|---|---|
| Nigerian English | `en` | Yes | Yes | Yes | Yes | `joseph` |
| Yoruba | `yo` | Yes | Yes | Yes | Yes | `aderonke` |
| Hausa | `ha` | Yes | Yes | Yes | Yes | `maryam` |
| Igbo | `ig` | Yes | Yes | Yes | Yes | `chinwe` |
| Nigerian Pidgin | `pcm` | Yes | Yes | Yes | Yes | `ufuoma` |

**Code-switching.** Text that mixes languages ("Ẹ kú àárọ̀ everyone, the meeting starts at ten") is read in one voice: set `language` to the main language of the text. Speech to text needs no language at all and handles mixed speech on its own.
