Add PlotWeaver to `~/.cursor/mcp.json` to use it in every project, or to `.cursor/mcp.json` in one project.

<Tabs>
  <Tab title="API key (recommended)">
    Set the key in your shell profile (`~/.zshrc`, `~/.bashrc`) so it never sits in a file you might share:

    ```bash
    export PLOTWEAVER_API_KEY="pw_prod_..."
    ```

    ```json ~/.cursor/mcp.json
    {
      "mcpServers": {
        "plotweaver": {
          "url": "https://mcp.plotweaver.app/mcp",
          "headers": {
            "X-API-Key": "${env:PLOTWEAVER_API_KEY}"
          }
        }
      }
    }
    ```

    Restart Cursor after setting the variable so it can read it. If PlotWeaver shows no tools, Cursor was probably opened from a launcher that does not see your shell profile: open it from a terminal with `cursor .`, or put the key itself in `~/.cursor/mcp.json`, which stays on your machine.
  </Tab>
  <Tab title="Sign in with PlotWeaver">
    Leave out the headers and Cursor signs in through your browser the first time a tool is used:

    ```json ~/.cursor/mcp.json
    {
      "mcpServers": {
        "plotweaver": {
          "url": "https://mcp.plotweaver.app/mcp"
        }
      }
    }
    ```

    The PlotWeaver page labels Cursor as an unverified app, because desktop apps sign in through your own computer. Approve it if you started the sign-in yourself.
  </Tab>
</Tabs>

Open **Cursor Settings > MCP** and check that PlotWeaver shows a green dot and its tools.

## Try it

In the agent chat:

> Generate the Pidgin and Hausa voice prompts in `ivr/prompts.json` as WAV files in `ivr/audio/`, using Tega for Pidgin and Maryam for Hausa.

> Make Yoruba, Hausa and Igbo versions of `onboarding-welcome.txt` as audio for the app's first screen.

Cursor's agent sends files from your project with `upload_file` and downloads the results into your project. See [Files and audio](/mcp/files-and-audio).
