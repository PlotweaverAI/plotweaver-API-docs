## Listing voices

`GET /v1/voices` returns the built-in voices and the voices you have cloned. Every built-in voice has a playable sample, so you can listen before you generate anything.

```bash
curl "https://api.plotweaver.app/v1/voices?language=ig" \
  -H "X-API-Key: $PLOTWEAVER_API_KEY"
```

```json
[
  {
    "voice_id": "chinwe",
    "name": "Chinwe",
    "type": "builtin",
    "model": "storm-v1",
    "gender": "female",
    "native_languages": ["ig"],
    "languages": ["ig"],
    "is_native": true,
    "cross_lingual": false,
    "sample_url": "https://.../samples/chinwe/ig.wav?X-Amz-Signature=...",
    "samples": [{ "language": "ig", "url": "https://.../samples/chinwe/ig.wav?..." }]
  }
]
```

| Query | Meaning |
|---|---|
| `language` | Every voice that can speak this language: the default voice and other native speakers first, then cross-lingual voices |
| `type` | `builtin` or `cloned` |

Sample links are signed and last one hour. Fetch the list again for fresh ones.

## Choosing a voice

Pass the voice id (`tola`) or the voice's name (`Adérónkẹ́`, with or without tone marks) as `voice_id`. Leave it out and you get the language's default voice.

Pick a voice whose native language matches your text whenever you can: a voice always sounds most natural in its own language.

## Cross-lingual voices

Every built-in STORM v1.5 voice can speak all five Nigerian languages. A Yoruba voice can read English, Hausa, Igbo or Pidgin, which is perfect for a brand voice that stays the same across languages.

A voice speaking a language other than its native one is **cross-lingual**. The voice list marks it `cross_lingual: true`, and `POST /v1/speech` answers with `X-Cross-Lingual: true`. Voices you clone with `storm-gust` also speak all five Nigerian languages.

## Other African languages

Every language STORM v3 speaks outside Nigeria lists STORM v3's own voice first, with the id `storm`. It is the default when you send no `voice_id`. STORM Ensemble 3.0 voices follow, each speaking its own language only:

```bash
curl "https://api.plotweaver.app/v1/voices?language=sw" -H "X-API-Key: $PLOTWEAVER_API_KEY"
```

returns `storm` and then the Swahili Ensemble voices. Languages that only Ensemble speaks use their first Ensemble voice by default. See [Languages](/languages) for every default.

## Your cloned voices

Voices you create with [voice cloning](/voice-cloning) appear in the same list with `"type": "cloned"`, and work everywhere a built-in voice does.

## Earlier voice ids

The ids of our first catalogue (`morenike`, `adewale`, `amina`, `adaeze`, `yemi`, `john`) still work. Each now speaks with a STORM v1.5 voice of the same gender, a native speaker of the requested language where the old voice had one. The `X-Voice` header names the voice used. They are no longer listed: move to the new ids when convenient.
